# SARIF schema provenance

`sarif-schema-2.1.0.json` is the OASIS SARIF 2.1.0 schema retrieved from:
https://github.com/oasis-tcs/sarif-spec/blob/main/sarif-2.1/schema/sarif-schema-2.1.0.json

It is vendored unchanged to validate reports offline. Copyright and license notices
are retained in the schema. This test asset is not included in the installed package.
